# نظام إدارة الشهادات والمراجعات — NQ

نظام ويب (ASP.NET Core 8 + SQL Server) فيه تسجيل دخول ومستخدمين وأدوار وصلاحيات بتتراجع على السيرفر، وسجل نشاط ونسخ احتياطي.

## هيكل الريبو
- **الجذر**: النسخة المبنية الجاهزة للتشغيل (`NqCert.dll` و`web.config` و`wwwroot/`). MonsterASP بيعمل `git clone` للريبو جوه `wwwroot` مباشرة من غير build.
- **`source/NqCert`**: الكود المصدري. الواجهة في `source/NqCert/wwwroot/index.html`.
- بعد أي تعديل في `source/`: شغّل `./build.sh` واعمل commit (أو سيب GitHub Actions يبني لوحده).

## التشغيل على MonsterASP.NET
1. لوحة التحكم ← الموقع ← **Deploy** ← **Github Deploy** ← حط رابط الريبو ← Enable (لازم `wwwroot` يكون فاضي).
2. افتح رابط الموقع. أول مرة هتظهر شاشة **إعداد النظام**:
   - اختار SQL Server والصق الـ Connection string من لوحة MonsterASP ← Databases.
   - أكّد بكلمة مرور حساب الطوارئ.
3. ادخل بـ `admin` / `admin` وغيّر كلمة المرور فورًا.

إعداد قاعدة البيانات بيتحفظ في `App_Data/db.json` على السيرفر (مش في الريبو). وفيه بديل: تحط `ConnectionStrings:Default` في `appsettings.json` على السيرفر.

## التحديث
اعمل push على GitHub، وبعدين من لوحة MonsterASP اضغط **Pull**. لو فشل التحديث لأن الملفات مستخدمة: اعمل Stop للموقع، وبعدين Pull، وبعدين Start.

## الأمان
- كلمات المرور متخزنة PBKDF2-SHA256، والجلسة في cookie من نوع HttpOnly وSameSite=Strict.
- بعد 5 محاولات دخول غلط الحساب بيتقفل 10 دقايق، ومحاولات الدخول محدودة بـ 10 في الدقيقة لكل IP.
- السيرفر بيرفض أي حفظ لبيانات المستخدم ملوش صلاحية تعديلها.
- **الريبو العام** فيه hash كلمة مرور الطوارئ (مش الكلمة نفسها). الأفضل تخلي الريبو Private.
